# European Health Data Platform simulation

This project is based on https://code.europa.eu/healthdataeu/healthdataeu-eu-dataset-catalogue/hdeu-starter-kit.git and retains the EUPL licensing from it.

## Project description

This is a derivative work of the HealthDataEU Central Platform  (https://code.europa.eu/healthdataeu/healthdataeu-eu-dataset-catalogue) meant for https://digicampus.fi/ course 'OY/MOOC: Introduction to European Health Data Space 2-3 cr, 2026'. It provides a modified composition of the central platform services such that there is no connectivity with the National Contact Points through the Domibus message broker network.
